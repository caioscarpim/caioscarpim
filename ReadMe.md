# 📊 Caio Scarpim

### Analista de Dados

Penso em dados desde antes de saber que isso tinha nome.
Sou a pessoa que olha para um problema e pergunta **"mas por quê isso acontece?"** — e foi exatamente isso que me trouxe para a análise de dados.

Trabalho com SQL, Power BI e Excel para transformar dados bagunçados em insights que orientam decisões. O que me move não é a ferramenta — é a pergunta certa antes de abrir qualquer planilha.
